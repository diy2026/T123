# 图鱼工作台 · 单文件版

> 一个**纯 HTML 单文件**的本地优先创作者工作台 —— 网站导航、选题管理、年度目标、专注计时、素材库、创作流程、数据看板、备忘录提醒，全部装进一个文件里。

**零后端 · 零依赖 · 零构建 · 数据只存在你的浏览器里**

---

## ✨ 功能特性

| 模块 | 说明 |
|---|---|
| 🌐 网站导航 | 多引擎搜索（必应/谷歌/百度等）、分类标签（常用/创作/工具/学习/资讯/娱乐/AI/站长）、站点锁定、收藏、分类管理 |
| 🎯 选题中心 | 选题库管理，状态流转：未开始 → 写作中 → 已完成，支持标签与筛选 |
| 🏁 今年目标 | 年度目标 + 进度条 + 截止日期，随时掌握完成情况 |
| ⏱️ 时间管理 | 专注计时（番茄钟），预设时长、今日/本周/累计投入统计 |
| 🗂️ 素材库 | 图片 / 视频 / 软件三大素材库，拖拽上传、标签、收藏、本地存储 |
| 🛠️ 创作工作流 | 创作项目分阶段管理（选题 → 大纲 → 初稿 → 发布），进度可视化 |
| 📊 数据总览 | 任务完成率、有效时长、项目状态分布等 KPI 看板 |
| 🔔 备忘录 | 到期提醒（到点弹窗）、全局置顶、一键完成 |
| 🎨 界面 | 深色/浅色主题一键切换、侧边栏收起、移动端自适应 |
| 💾 数据 | 一键导出备份 / 导入恢复，本地数据随时迁移 |

## 🚀 快速开始

**方式一：直接打开**
双击 `index - 副本.html` 即可使用，无需安装任何东西。

**方式二：部署到静态托管**
把 `index.html` 上传到任意静态托管平台即可：
- GitHub Pages
- Vercel / Netlify / Cloudflare Pages
- 任意 Web 服务器 / 虚拟主机

## 💾 数据与隐私

- 所有业务数据保存在浏览器 `localStorage`（素材文件存 IndexedDB），**不上传任何服务器**。
- 首次打开自动填充示例数据，可在「网站管理 → 导出备份」导出为 JSON 文件保存。
- 换设备 / 换浏览器时，用「导入恢复」把备份 JSON 导回即可。
- 清除浏览器站点数据会清空本地数据，**建议定期导出备份**。

## ⚙️ 自定义

- 主题：侧边栏底部「深色/浅色模式」开关。
- 搜索引擎：搜索框左侧下拉可切换（必应、谷歌、百度、知乎等）。
- 网站分类：网站管理菜单 → 管理分类，可增删分类与重命名。
- 锁定站点：一键锁定全部站点，防止误点跳转。

## 🛠️ 技术栈

- 原生 HTML + CSS + JavaScript（ES5 兼容写法）
- 无框架、无构建步骤、无外部运行时依赖
- 数据持久化：`localStorage` + `IndexedDB`
